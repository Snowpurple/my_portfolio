# Sneha Yadav portfolio

Open `index.html` in a browser (or use VS Code Live Server). No build step.

## Fill in
1. **Images**: see `assets/README.txt` for the file names.
2. **Resume and LinkedIn**: in `index.html`, find the two `<a ... href="#">` buttons in the "Let's Connect" section and paste your links in `href`. Until then they show "link not added yet".
   For a PDF resume put it in `assets/resume.pdf` and use `href="assets/resume.pdf"`.
3. **Case studies and prototype links**: edit `projects.js`. Paste each Figma prototype link into `prototypeUrl`, add `sections` (problem, process, ...) and `images`. Anything left empty is hidden. A Figma prototype link also shows as an embedded prototype on the page.
4. Project card text, the "Closet" and "Coming soon" cards: `index.html` (projects section).

## What it does
- Menu items scroll to Home, Projects, About Me and the Resume section; the current section is highlighted.
- Clicking Kisan-Verse or Ishavarya opens its case study page with a prototype button.
- The logo in the nav, the Home photo and the About photo tilt on hover.
- The Home arrow keeps bouncing and scrolls to Projects when clicked.
- Responsive: menu becomes a hamburger on phones, grids stack, no sideways scrolling.

Fonts load from Google Fonts (Inter, Protest Riot, Licorice).
